# Utilidata

> Utilidata builds Karman, a distributed AI platform that runs on a custom NVIDIA
> system-on-module embedded directly into electrical infrastructure — smart meters and
> grid-edge devices on the utility side, PDUs and power trays inside AI data centers.
> Karman processes high-resolution AC metrology locally to produce "data products" such
> as Power Quality Analytics, enabling millisecond-level power control, GPU/PSU failure
> prediction, phase balancing and power-aware scheduling.

This file was generated by API Evangelist from publicly available material. Utilidata
does not publish an llms.txt of its own (https://utilidata.com/llms.txt returns 404 as of
2026-08-05).

## What the machine-readable surface actually is

Utilidata publishes **no HTTP API**. There is no OpenAPI, no GraphQL SDL, no AsyncAPI, no
MCP server, and no `/.well-known/` discovery surface on any Utilidata host. What it does
publish is a **telemetry contract**: Karman devices emit Protocol Buffers frames over
ZeroMQ, and Utilidata ships an Apache-2.0 reference implementation that consumes them.

- Protobuf package: `utilidata.karman.bibimbap.v1`
- Transport: ZeroMQ PUB/SUB, port 5557, topic `cycle-aligned`
- Root message: `CompositeJoinedCalculations`
- Consumer projections: Prometheus `/metrics` on port 9105 (44 gauges), TimescaleDB
  hypertable `bibimbap`
- Endpoints are on-device / on-premise. There is no hosted, internet-reachable API host.

`developer.utilidata.com` is advertised as the Karman developer portal but has been
serving an expired TLS certificate since 2026-07-07 and returns 404 for every path.

## Source code

- [power-aware-module](https://github.com/utilidata/power-aware-module): Karman Power Aware Module — Rust reference implementation (data-replay, data-db, data-exporter) plus a Helm chart, Grafana dashboards and four recorded B200 GPU power datasets. Apache-2.0.
- [nvml-wrapper](https://github.com/utilidata/nvml-wrapper): Safe Rust wrapper for the NVIDIA Management Library.
- [GitHub organization](https://github.com/utilidata)

## Container images

- [karman/data-exporter](https://gallery.ecr.aws/k0f5s7n3/karman/data-exporter): ZeroMQ subscriber that exports Karman power analytics as Prometheus gauges.
- [karman/data-db](https://gallery.ecr.aws/k0f5s7n3/karman/data-db): TimescaleDB sink for per-cycle power analytics.
- [karman/data-replay](https://gallery.ecr.aws/k0f5s7n3/karman/data-replay): Replays recorded lab datasets as protobuf frames, so the stack runs without Karman hardware.
